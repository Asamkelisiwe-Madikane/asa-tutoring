# Asa's Future Tutoring Centre

## Website Project

Asa's Future Tutoring Centre is a tutoring-centre website developed to provide learners and parents with information about tutoring services, subjects, enquiries, contact details and online tutoring.

The website was created as part of a web development project.

# 2. Part 1 Project Details

Part 1 of the project focused on planning and preparing the website before and during development.

The project involved creating a website for a fictional tutoring organisation called Asa's Future Tutoring Centre.

The main purpose of the website is to provide learners and parents with information about the tutoring centre and make it easier for them to find suitable academic support.

## Part 1 included:

- Selecting the organisation for the website.
- Identifying the target audience.
- Establishing the purpose of the website.
- Identifying the services offered.
- Planning the website structure.
- Creating a sitemap.
- Planning the website content.
- Researching and sourcing suitable content.
- Identifying suitable images and media.
- Planning the navigation structure.
- Planning the required website pages.
- Developing the website using HTML.
- Adding CSS styling where required.
- Testing the website and correcting errors.

# 4. Website Objectives

The main objectives of the website are to:

1. Provide information about Asa's Future Tutoring Centre.
2. Explain the tutoring services available.
3. Provide information about the subjects offered.
4. Allow learners and parents to make enquiries.
5. Provide contact information.
6. Provide information about online tutoring.
7. Promote the tutoring centre through social-media platforms.
8. Make important information easy to find.
9. Create a simple and accessible website for learners and parents.

# 5. Website Features

The website contains several features designed to improve the user experience.

## Navigation Menu

Every main page contains links to:

- Home
- About Us
- Services
- Enquiry
- Contact

This allows visitors to move between the different pages.

## About Us

The About Us page provides information about:

- The organisation's story.
- The organisation's mission.
- The organisation's vision.
- Core values.
- Tutors.
- The organisation's commitment to learners.

## Services

The Services page provides information about:

- Mathematics
- Physical Sciences
- Life Sciences
- Online Tutoring

## Enquiry Form

The enquiry page allows users to provide information such as:

- First name
- Surname
- Email address
- Telephone number
- Grade
- Subject
- Preferred tutoring method
- Message

## Contact Form

The Contact page contains a form that allows visitors to send a message to the tutoring centre.

## Map

A map has been added to the Contact page to show the general location of the tutoring centre in Gqeberha, Eastern Cape.

## Social Media

The Contact page includes planned social-media platforms:

- Facebook
- Instagram
- WhatsApp Business

The organisation is fictional, so these platforms are currently represented as project content rather than real organisation profiles.

## Images

Images are used to represent tutoring subjects and services.

These include:

- Mathematics
- Physical Sciences
- Life Sciences
- Online Tutoring

Social-media logos are also included.
